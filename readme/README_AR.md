## حول التطبيق

تطبيق Xender هو التطبيق الرائد عالميًا لنقل الملفات عبر الأنظمة المختلفة، وهو متاح على Android وiOS وWindows وmacOS والويب.

إلى جانب مشاركة الملفات، يُعد أداة متكاملة تضم مشغل موسيقى وفيديو، ومحول صوتيات، ومحمل فيديوهات التواصل الاجتماعي، ومنظف مساحة التخزين.

مجاني، سريع، متوافق، وسهل الاستخدام.

## المميزات

- متعدد الأنظمة: يدعم Android وiOS وWindows وmacOS.
- التوافق مع أجهزة متعددة: يعمل على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر المحمولة والمكتبية.
- نقل لاسلكي: شارك الملفات عبر Wi-Fi ونقطة الاتصال الشخصية (Hotspot)—دون الحاجة إلى كابلات.
- مشاركة بدون بيانات: انقل الملفات عبر الشبكات المحلية دون استهلاك بيانات الهاتف المحمول.
- مشغل موسيقى متعدد الاستخدامات: يدعم البحث عن كلمات الأغاني، والتحكم في سرعة التشغيل، وتضخيم الصوت، ومؤقت النوم.
- مشغل فيديو قوي: يدعم التحكم بالإيماءات، والترجمات المدمجة والخارجية، وتبديل المسارات الصوتية، وقفل التدوير، وقفل الشاشة، وتضخيم الصوت، ومؤقت النوم.
- محول ToMP3: استخرج الصوت بسرعة من ملفات الفيديو للاستماع السلس مع إيقاف تشغيل الشاشة.
- محمل فيديوهات التواصل الاجتماعي: احفظ الفيديوهات بسهولة لتشغيلها دون اتصال بالإنترنت—يدعم Instagram وFacebook وTikTok وX/Twitter وThreads وBluesky وTumblr وحالات WhatsApp (تطبيق YouTube غير مدعوم).
- منظف مساحة التخزين: حرر مساحة التخزين عن طريق الحذف الجماعي للصور المتكررة أو المتشابهة ولقطات الشاشة.
- والمزيد: ميزات جديدة في الطريق إليك.
