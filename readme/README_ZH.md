## 關於

Xender 是全球領先的跨平台檔案傳輸應用程式，支援 Android、iOS、Windows、macOS 及網頁版。

除了檔案分享之外，它還是一款全方位的實用工具，內建音樂與影片播放器、音訊轉換器、社群影片下載器以及儲存空間清理工具。

免費、快速、高相容性且簡單易用。

## 功能特色

- 跨平台支援：支援 Android、iOS、Windows 與 macOS。
- 多裝置相容：適用於手機、平板電腦、筆記型電腦與桌上型電腦。
- 無線傳輸：透過 Wi-Fi 與個人熱點分享檔案——無需任何傳輸線。
- 免流量分享：透過區域網路傳輸，完全不消耗行動數據流量。
- 多功能音樂播放器：支援歌詞搜尋、播放速度調整、音量增強以及睡眠定時器。
- 強大的影片播放器：支援手勢控制、內嵌與外掛字幕、音軌切換、旋轉鎖定、螢幕鎖定、音量增強以及睡眠定時器。
- ToMP3 音訊轉換器：快速從影片檔案中提取音訊，享受流暢的關螢幕背景播放體驗。
- 社群影片下載器：輕鬆儲存影片以供離線播放——支援 Instagram、Facebook、TikTok、X/Twitter、Threads、Bluesky、Tumblr 與 WhatsApp 動態（不支援 YouTube）。
- 儲存空間清理工具：透過批次刪除重複或相似的照片與螢幕截圖，快速釋放儲存空間。
- 更多功能：全新功能正在開發中，敬請期待。
