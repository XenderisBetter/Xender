## ስለ መተግበሪያው

Xender በAndroid፣ iOS፣ Windows፣ macOS እና በድር (Web) ላይ የሚገኝ የዓለማችን ቀዳሚ የተለያዩ መድረኮች (Cross-Platform) የፋይል ማስተላለፊያ መተግበሪያ ነው።

ከፋይል ማጋራት ባለፈ፣ የሙዚቃ እና የቪዲዮ ማጫወቻ፣ የድምፅ መቀየሪያ፣ የማህበራዊ ሚዲያ ቪዲዮ ማውረጃ እና የማከማቻ ማጽጃን ያካተተ ሁሉን-አቀፍ መገልገያ ነው።

ነፃ፣ ፈጣን፣ ተስማሚ እና ለመጠቀም ቀላል።

## ባህሪያት

- የተለያዩ መድረኮች ድጋፍ (Cross-Platform): Android፣ iOS፣ Windows እና macOSን ይደግፋል።
- የብዙ መሣሪያዎች ተኳኋኝነት: በስልኮች፣ በታብሌቶች፣ በላፕቶፖች እና በዴስክቶፖች ላይ ይሰራል።
- ገመድ አልባ ማስተላለፍ: በWi-Fi እና በግል ሆትስፖት (Hotspot) ያጋሩ—ምንም ገመድ አያስፈልግም።
- ያለ ዳታ ማጋራት: ምንም የሞባይል ዳታ ሳይጠቀሙ በአካባቢያዊ አውታረ መረቦች (Local Networks) ያስተላልፉ።
- ሁለገብ የሙዚቃ ማጫወቻ: የግጥም ፍለጋን፣ የማጫወቻ ፍጥነት መቆጣጠሪያን፣ የድምፅ ማጉያን እና የእንቅልፍ ሰዓት ቆጣሪን ይደግፋል።
- ኃይለኛ የቪዲዮ ማጫወቻ: የእጅ ምልክት መቆጣጠሪያዎችን፣ የተካተቱ እና ውጫዊ የትርጉም ጽሑፎችን (Subtitles)፣ የድምፅ ትራክ መቀየርን፣ የማዞሪያ መቆለፊያን፣ የስክሪን መቆለፊያን፣ የድምፅ ማጉያን እና የእንቅልፍ ሰዓት ቆጣሪን ይደግፋል።
- ToMP3 መቀየሪያ: ስክሪኑ ጠፍቶ እንኳን ያለማቋረጥ ለማዳመጥ ከቪዲዮ ፋይሎች ላይ ድምፅን በፍጥነት ያውጡ።
- የማህበራዊ ቪዲዮ ማውረጃ: ከመስመር ውጭ ለማጫወት ቪዲዮዎችን በቀላሉ ያስቀምጡ—Instagram፣ Facebook፣ TikTok፣ X/Twitter፣ Threads፣ Bluesky፣ Tumblr እና WhatsApp Statusን ይደግፋል (YouTube አይደገፍም)።
- የማከማቻ ማጽጃ: የተደጋገሙ ወይም ተመሳሳይ ፎቶዎችን እና የስክሪን ፎቶዎችን (Screenshots) በጅምላ በመሰረዝ ቦታ ያስለቅቁ።
- እና ተጨማሪ: አዳዲስ ባህሪያት በመምጣት ላይ ናቸው።
