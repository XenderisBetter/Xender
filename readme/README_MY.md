## အက်ပ်အကြောင်း

Xender သည် Android၊ iOS၊ Windows၊ macOS နှင့် ဝဘ်တို့တွင် အသုံးပြုနိုင်သော ကမ္ဘာ့ဦးဆောင် ပလက်ဖောင်းစုံသုံး ဖိုင်လွှဲပြောင်းသည့် အက်ပ်ဖြစ်သည်။

ဖိုင်မျှဝေခြင်းအပြင် တေးဂီတနှင့် ဗီဒီယိုဖွင့်စက်၊ အသံပြောင်းစက် (audio converter)၊ ဆိုရှယ်မီဒီယာ ဗီဒီယိုဒေါင်းလုဒ်ဆွဲစက်နှင့် သိုလှောင်မှုရှင်းလင်းစက်တို့ ပါဝင်သည့် အစုံသုံး အက်ပ်တစ်ခုဖြစ်သည်။

အခမဲ့၊ မြန်ဆန်ပြီး၊ စက်ပစ္စည်းစုံနှင့် ကိုက်ညီကာ အသုံးပြုရ လွယ်ကူသည်။

## လုပ်ဆောင်ချက်များ

- ပလက်ဖောင်းစုံ အထောက်အပံ့: Android၊ iOS၊ Windows နှင့် macOS တို့ကို ပံ့ပိုးပေးသည်။
- စက်ပစ္စည်းစုံ ကိုက်ညီမှု: ဖုန်းများ၊ တက်ဘလက်များ၊ လက်ပ်တော့များနှင့် ဒက်စ်တော့ကွန်ပျူတာများတွင် အလုပ်လုပ်သည်။
- ကြိုးမဲ့ လွှဲပြောင်းခြင်း: Wi-Fi နှင့် ကိုယ်ပိုင် Hotspot မှတစ်ဆင့် မျှဝေပါ—ကြိုးများ မလိုအပ်ပါ။
- ဒေတာမကုန်ဘဲ မျှဝေခြင်း: မိုဘိုင်းဒေတာ လုံးဝမကုန်ဘဲ လိုကယ်ကွန်ရက်များမှတစ်ဆင့် ဖိုင်လွှဲပြောင်းပါ။
- စွယ်စုံသုံး တေးဂီတဖွင့်စက်: သီချင်းစာသားရှာဖွေခြင်း၊ ဖွင့်သည့်အမြန်နှုန်း ထိန်းချုပ်ခြင်း၊ အသံချဲ့စက်နှင့် အိပ်ချိန်သတ်မှတ်စက်တို့ကို ပံ့ပိုးပေးသည်။
- စွမ်းဆောင်ရည်မြင့် ဗီဒီယိုဖွင့်စက်: လက်ဟန်ဖြင့် ထိန်းချုပ်မှုများ၊ အတွင်းနှင့် အပြင် စာတန်းထိုးများ (subtitles)၊ အသံလမ်းကြောင်း ပြောင်းလဲခြင်း၊ မျက်နှာပြင်လှည့်ခြင်းလော့ခ်၊ မျက်နှာပြင်လော့ခ်၊ အသံချဲ့စက်နှင့် အိပ်ချိန်သတ်မှတ်စက်တို့ကို ပံ့ပိုးပေးသည်။
- ToMP3 ပြောင်းစက်: မျက်နှာပြင်ပိတ်ထားချိန်တွင် အဆင်ပြေချောမွေ့စွာ နားဆင်နိုင်ရန် ဗီဒီယိုဖိုင်များမှ အသံကို အမြန်ထုတ်ယူပါ။
- ဆိုရှယ်ဗီဒီယို ဒေါင်းလုဒ်ဆွဲစက်: အော့ဖ်လိုင်းကြည့်ရှုရန် ဗီဒီယိုများကို အလွယ်တကူ သိမ်းဆည်းပါ—Instagram၊ Facebook၊ TikTok၊ X/Twitter၊ Threads၊ Bluesky၊ Tumblr နှင့် WhatsApp Status တို့ကို ပံ့ပိုးပေးသည် (YouTube ကို မပံ့ပိုးပါ)။
- သိုလှောင်မှု ရှင်းလင်းစက်: ထပ်နေသော သို့မဟုတ် ဆင်တူသော ဓာတ်ပုံများနှင့် စခရင်ရှော့များကို တစ်ပြိုင်နက် ဖျက်ပစ်ခြင်းဖြင့် နေရာလွတ် ရယူပါ။
- အခြားအရာများ: လုပ်ဆောင်ချက်အသစ်များ မကြာမီ လာမည်။
