## Tentang

Xender adalah aplikasi transfer file lintas platform terkemuka di dunia, tersedia di Android, iOS, Windows, macOS, dan web.

Lebih dari sekadar berbagi file, Xender adalah aplikasi utilitas lengkap (all-in-one) yang dilengkapi pemutar musik dan video, konverter audio, pengunduh video media sosial, serta pembersih penyimpanan.

Gratis, cepat, kompatibel, dan mudah digunakan.

## Fitur

- Lintas Platform: Mendukung Android, iOS, Windows, dan macOS.
- Kompatibilitas Multi-Perangkat: Berfungsi di ponsel, tablet, laptop, dan komputer desktop.
- Transfer Nirkabel: Bagikan melalui Wi-Fi dan hotspot pribadi—tanpa perlu kabel.
- Berbagi Tanpa Kuota Data: Transfer melalui jaringan lokal tanpa menggunakan data seluler sama sekali.
- Pemutar Musik Serbaguna: Mendukung pencarian lirik, kontrol kecepatan pemutaran, penguat volume, dan pengatur waktu tidur.
- Pemutar Video Tangguh: Mendukung kontrol gestur, subtitle bawaan dan eksternal, pergantian trek audio, kunci rotasi, kunci layar, penguat volume, dan pengatur waktu tidur.
- Konverter ToMP3: Ekstrak audio dari file video dengan cepat untuk mendengarkan secara lancar saat layar mati.
- Pengunduh Video Sosial: Simpan video dengan mudah untuk diputar secara offline—mendukung Instagram, Facebook, TikTok, X/Twitter, Threads, Bluesky, Tumblr, dan Status WhatsApp (YouTube tidak didukung).
- Pembersih Penyimpanan: Bebaskan ruang penyimpanan dengan menghapus foto duplikat atau serupa serta tangkapan layar secara massal.
- Dan Lainnya: Fitur-fitur baru segera hadir.
