## વિશે

Xender એ વિશ્વની અગ્રણી ક્રોસ-પ્લેટફોર્મ ફાઇલ ટ્રાન્સફર એપ્લિકેશન છે, જે Android, iOS, Windows, macOS અને વેબ પર ઉપલબ્ધ છે.

ફાઇલ શેરિંગ ઉપરાંત, તે એક ઓલ-ઇન-વન યુટિલિટી છે જેમાં મ્યુઝિક અને વિડિયો પ્લેયર, ઓડિયો કન્વર્ટર, સોશિયલ વિડિયો ડાઉનલોડર અને સ્ટોરેજ ક્લીનર સામેલ છે.

મફત, ઝડપી, સુસંગત અને ઉપયોગમાં સરળ.

## વિશેષતાઓ

- ક્રોસ-પ્લેટફોર્મ: Android, iOS, Windows અને macOS ને સપોર્ટ કરે છે.
- મલ્ટિ-ડિવાઇસ સુસંગતતા: ફોન, ટેબ્લેટ, લેપટોપ અને ડેસ્કટોપ પર કામ કરે છે.
- વાયરલેસ ટ્રાન્સફર: Wi-Fi અને પર્સનલ હોટસ્પોટ દ્વારા શેર કરો—કોઈ કેબલની જરૂર નથી.
- ડેટા-ફ્રી શેરિંગ: ઝીરો મોબાઇલ ડેટા વપરાશ સાથે લોકલ નેટવર્ક પર ફાઇલ ટ્રાન્સફર કરો.
- બહુમુખી મ્યુઝિક પ્લેયર: લિરિક્સ સર્ચ, પ્લેબેક સ્પીડ કંટ્રોલ, વોલ્યુમ બૂસ્ટર અને સ્લીપ ટાઇમરને સપોર્ટ કરે છે.
- પાવરફુલ વિડિયો પ્લેયર: જેસ્ચર કંટ્રોલ્સ, એમ્બેડેડ અને એક્સટર્નલ સબટાઇટલ્સ, ઓડિયો ટ્રેક સ્વિચિંગ, રોટેશન લોક, સ્ક્રીન લોક, વોલ્યુમ બૂસ્ટર અને સ્લીપ ટાઇમરને સપોર્ટ કરે છે.
- ToMP3 કન્વર્ટર: સ્ક્રીન બંધ રાખીને સરળતાથી સાંભળવા માટે વિડિયો ફાઇલોમાંથી ઝડપથી ઓડિયો કાઢો.
- સોશિયલ વિડિયો ડાઉનલોડર: ઓફલાઇન પ્લે કરવા માટે વિડિયો સરળતાથી સેવ કરો—Instagram, Facebook, TikTok, X/Twitter, Threads, Bluesky, Tumblr અને WhatsApp Status ને સપોર્ટ કરે છે (YouTube સપોર્ટેડ નથી).
- સ્ટોરેજ ક્લીનર: ડુપ્લિકેટ અથવા સમાન ફોટા અને સ્ક્રીનશોટને એકસાથે ડિલીટ કરીને જગ્યા ખાલી કરો.
- અને વધુ: નવી વિશેષતાઓ ટૂંક સમયમાં આવી રહી છે.
