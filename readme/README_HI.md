## परिचय

Xender दुनिया का अग्रणी क्रॉस-प्लेटफ़ॉर्म फ़ाइल ट्रांसफ़र ऐप है, जो Android, iOS, Windows, macOS और वेब पर उपलब्ध है।

फ़ाइल शेयरिंग के अलावा, यह एक ऑल-इन-वन यूटिलिटी ऐप है जिसमें म्यूज़िक और वीडियो प्लेयर, ऑडियो कन्वर्टर, सोशल वीडियो डाउनलोडर और स्टोरेज क्लीनर शामिल हैं।

मुफ़्त, तेज़, कम्पैटिबल और इस्तेमाल करने में आसान।

## विशेषताएँ

- क्रॉस-प्लेटफ़ॉर्म: Android, iOS, Windows और macOS को सपोर्ट करता है।
- मल्टी-डिवाइस कम्पैटिबिलिटी: फ़ोन, टैबलेट, लैपटॉप और डेस्कटॉप पर काम करता है।
- वायरलेस ट्रांसफ़र: Wi-Fi और पर्सनल हॉटस्पॉट के ज़रिए शेयर करें—किसी केबल की ज़रूरत नहीं।
- डेटा-फ़्री शेयरिंग: बिना मोबाइल डेटा खर्च किए लोकल नेटवर्क के ज़रिए फ़ाइलें ट्रांसफ़र करें।
- बहुमुखी म्यूज़िक प्लेयर: लिरिक्स सर्च, प्लेबैक स्पीड कंट्रोल, वॉल्यूम बूस्टर और स्लीप टाइमर को सपोर्ट करता है।
- पावरफ़ुल वीडियो प्लेयर: जेस्चर कंट्रोल, एम्बेडेड और एक्सटर्नल सबटाइटल, ऑडियो ट्रैक स्विचिंग, रोटेशन लॉक, स्क्रीन लॉक, वॉल्यूम बूस्टर और स्लीप टाइमर को सपोर्ट करता है।
- ToMP3 कन्वर्टर: स्क्रीन बंद करके बिना रुकावट ऑडियो सुनने के लिए वीडियो फ़ाइलों से तुरंत ऑडियो निकालें।
- सोशल वीडियो डाउनलोडर: ऑफ़लाइन देखने के लिए आसानी से वीडियो सेव करें—Instagram, Facebook, TikTok, X/Twitter, Threads, Bluesky, Tumblr और WhatsApp Status को सपोर्ट करता है (YouTube सपोर्टेड नहीं है)।
- स्टोरेज क्लीनर: डुप्लिकेट या मिलते-जुलते फ़ोटो और स्क्रीनशॉट को एक साथ हटाकर स्टोरेज स्पेस खाली करें।
- और भी बहुत कुछ: नए फ़ीचर्स जल्द आ रहे हैं।
